# Support

Use the GitHub issue tracker at <https://github.com/gaming09/amcrest-ptz-bridge/issues>.

Include the following when reporting a problem:

- camera model and firmware version;
- Unraid and Frigate versions;
- container image tag;
- sanitized bridge logs;
- whether the Amcrest mobile application can move the camera.

Never post camera passwords, externally reachable addresses, or unsanitized packet captures.
